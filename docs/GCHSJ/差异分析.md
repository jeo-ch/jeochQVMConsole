## §0 结论速览

1. **QVMConsole 与两大竞品的根本差异是「发布形态」**：SMTXOS 是自编译 CentOS 7 全盘发行版，HCI 是自解压 shell 大包，QVMConsole 是「附加式 install.sh 面板」——问题域不同，**不追求做发行版**。
2. 但竞品在**安装可靠性、升级工程化、安装期安全基线、无人值守**四方面有 12 条可吸收优化点（P0-P3），不涉及造 OS，可直接落地。
3. **P0-2（firewalld min 0.8→0.4）与 P0-3（glibc 2.17 CI 真兼容）** 是当前国产化方案里最容易被现场打脸的缺口：老系统（CentOS 7 / 麒麟 V10 0.6.x）会误报 critical、compat 档可能 "Symbol not found"。建议最先实施。

## §2 竞品机制拆解（逐产品）

### §2.1 SMTXOS 6.2（SmartX）——Kickstart 自动化与安全基线

**安装基线（isolinux/isolinux.cfg + ks_*.cfg）**：

- 卷标 `SMARTXOS-2`，引导参数 `inst.stage2=hd:LABEL=SMARTXOS-2 ks=hd:LABEL=SMARTXOS-2:/ks_automatic.cfg nvme_core.multipath=0 quiet`。
- **双引导**：BIOS（isolinux）+ UEFI（grub.cfg）+ PXE；`ks_automatic.cfg` 为默认无人值守路径，`ks_manual.cfg` 为手动。
- **缺陷（可借鉴教训）**：isolinux.cfg 两个菜单项共用 `label linux`，后者覆盖前者——BIOS 下手动安装菜单实际失效（UEFI grub.cfg 正常）。**启示：多菜单项必须用唯一 label，且需逐项验证。**

**ks 头部基线（安全默认值）**：

- `rootpw` SHA-512 预置；**账号分层**：`user admin`（产品控制台账号）+ `user smartx`（厂商售后账号，供支持介入）。
- `firewall --disabled` + `selinux --disabled`（存储/虚拟化栈接管，避免策略误伤数据面）；`install/skipx/zerombr`；`reboot --eject`；`Asia/Shanghai UTC`；`%include /tmp/part.ks` 动态分区。
- 内核引导参数**按 CPU 厂商分派**：HygonGenuine/AuthenticAMD → `intel_idle.max_cstate=0 processor.max_cstate=1 intel_pstate=disable transparent_hugepage=never slab_nomerge tsx=on no5lvl megaraid_sas.scmd_timeout=20 nvme_core.multipath=0`；VMware 环境减半参数。

**%pre 编排（磁盘识别三级回退）**：

- 磁盘自动识别：白名单（品牌 RAID/BOSS 卡）→ 控制器拓扑（PCI 控制器挂盘数）→ 人工输入。
- 重装兼容旧部署：清理既有 md RAID / LVM（`clean_exist_raid`/`remove_lvm_disk` 函数），杜绝残留 PV/LV 干扰。
- `%pre` 状态文件全量带入 chroot；SSD Trim 用 Python 兜底。

**安装期安全基线固化（%post，可借鉴）**：

- THP off、slab_nomerge（内存安全 + 性能）；命令审计 `/var/log/bash.log`（追加-only `chattr +a` + `chmod a+w`）。
- 精简布局：无 LVM 无 swap，系统盘双盘 RAID1 可选，数据盘裸盘不动（「只动启动盘」原则）。
- 内置 smartd / mdmonitor / crond 服务。

**软件栈收敛**：`@smartx` 单一包组 + `cluster-installer` 注入标记（`###CLUSTER_INSTALLER_PRE/POST_SCRIPT###`），供多节点自动化安装器复用。

### §2.2 HCI 6.11.1（深信服 VMP）——整盘镜像与升级工程化

**加密与反逆向**：

- 除 `EFI/BOOT/grub.cfg`（明文）与 `install/vmp.pkg` 自解压外壳前 610 行（明文）外，vmlinuz/initrd.gz/rd.gz/isolinux.cfg 均为密文。
- grub 菜单 "SANGFOR HCI Installer"，含 "Low Latency Mode" 菜单；**arbiter 变体**（`*.arbiter_override` 覆盖文件）移除该菜单 → 同一镜像按覆盖文件产出「普通节点 / 仲裁节点」两种角色。

**安装分层（镜像烧写式）**：

- `install/rd.gz` = 602MB 基础系统镜像，**整盘写入**；`install/vmp.pkg` = 4.1GB **DES3 加密固件升级包**（自解压）；`install.amd/` 安装器密文。
- 防误删确认：格式化磁盘必须键入 `format` 确认。

**升级工程化（vmp.pkg 自解压外壳，可借鉴）**：

- 多阶段：`unpack → ing → outcfg`；`$update_dir/ing`（进行中标记）、`$outcfg`（输出配置保留，供下次取）、`$die_file`（失败写错误信息）、`$cleanpath`（是否清理）、`diewithclean` 按 `is_success` 决定是否清 tmpdir。
- pid 文件锁防重入 + **磁盘空间预检**（df 阈值，如 4.5GB）+ 失败清理 + `fsync`/`fadvise`（防掉电丢包）。
- 双轨升级框架（coldupdate/update-v2）；loop 镜像解压缓冲。

**组件体系**：aSV（KVM）/ aSAN（分布式存储）/ aNET（SDN）/ aSEC（安全）；x86_64 + ARM64/IA32 三架构 EFI 单 ISO。

## §3 差异点汇总（QVMConsole 缺口清单）

| # | 维度 | SMTXOS / HCI 做法 | QVMConsole 现状 | 差距等级 |
|---|---|---|---|---|
| 1 | 磁盘识别 | SMTX 三级识别（白名单→拓扑→人工） | `detect_root_size`/`setup_quota` 无磁盘白名单 | 高（配额盘选错→数据盘被清） |
| 2 | 重装兼容 | SMTX 清理既有 md RAID / LVM | `uninstall_app` 只清 firewalld zone | 高（已装面板机器重装残留 PV） |
| 3 | 命令审计 | SMTX `/var/log/bash.log`（chattr +a） | 无 | 高（等保「操作审计」合规） |
| 4 | 升级健壮性 | HCI pid 锁 + df 预检 + 失败清理 | `get_release` 无锁无空间预检 | 高（/boot 小分区被挤爆） |
| 5 | 安装恢复 | HCI `ing/outcfg/die_file` 状态文件 | 无 stage 持久化、无 `--resume` | 中 |
| 6 | 权限加固 | 商用安装器 .env 600 | `.env` 已 chmod 600；敏感目录未 700 | 中（部分已做） |
| 7 | 内核参数 | SMTX 按 CPU 厂商分派（Hygon 等） | 无 CPU 厂商分支 | 高（国产 CPU 性能/稳定性） |
| 8 | 数据盘保护 | SMTX「只动启动盘」+ HCI 磁盘签名 | setup_quota 可能触碰全部磁盘 | 中 |
| 9 | 升级回滚 | SMTX hotfix `%pretrans` 备份 | 无 INSTALL_DIR.bak | 中 |
| 10 | 包完整性 | SMTX isomd5sum + RPM GPG；HCI 解密校验 | 无 SHA256/签名校验 | 中 |
| 11 | 账号分层 | SMTX admin（产品）+ smartx（售后） | 单一 admin | 低 |
| 12 | 组件版本 | SMTX 各 RPM 独立版本管理 | M7 已做 18 项 component_health | 已覆盖 |
| 13 | 防火墙 | SMTX 0.4.x 直接 disabled | M0-M5 双后端抽象 | 已覆盖（但见 P0-2） |

### P2：观测性与运维（3 条）

#### P2-8　bash 审计日志（PROMPT_COMMAND）+ kdump 建议提示

- **现状**：install.sh 未做 shell 审计配置；不检测 kdump。
- **竞品**：SMTXOS ks.cfg:923-926 `PROMPT_COMMAND` 记录时间+whoami+who -u+RC 到 `/var/log/bash.log`（`chmod a+w` + `chattr +a`）；kdump 裸金属 crashkernel=2048M,high / 虚拟化 512M。
- **建议**：
